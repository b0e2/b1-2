# 마이그레이션 실행 순서

Supabase 대시보드 > SQL Editor 에서 순서대로 실행한다.

| 파일 | 시점 | 되돌리기 |
|---|---|---|
| `20260910_add_tags.sql` | 태그 도입 | `20260910_rollback_tags.sql` |
| `20260910_drop_subject.sql` | 배포 직전 | 불가. 실행 전 데이터를 내려받는다 |

`20260910_add_tags.sql` 은 `subject` 를 남겨 둔다. 컬럼을 지우는 것은 되돌릴 수 없으므로
전체 기능이 안정된 뒤 배포 단계에서 따로 실행한다. 그 전까지는 롤백 파일로 언제든 되돌릴 수 있다.
